## Project Overview
The Student Consultation Booking System is a web-based application designed to streamline academic consultations between students and lecturers. It replaces manual scheduling (via WhatsApp or email) with an automated system supporting slot creation, booking management, status workflows (Pending, Approved, Rejected, Completed), and double-booking prevention.

## Features
- **User Authentication:** Secure login/logout with role-based access control for Students and Lecturers.
- **Slot Management:** Lecturers can create slots specifying Face-to-Face location or Online meeting links.
- **Booking & Prevention:** Students can book available slots with built-in double-booking conflict prevention.
- **Status Workflow:** Complete tracking from Pending to Approved, Completed, or Rejected.
